# Perfiles VPN locales

Guarda aquí los archivos `.ovpn` de Hack The Box. Las configuraciones VPN se
ignoran deliberadamente en Git porque pueden contener certificados y claves
asociados a una cuenta.

La tarjeta VPN de Polybar abre un selector con los perfiles disponibles. Cuando
existe una conexión iniciada por el selector, permite desconectarla o consultar
el log. El clic derecho abre directamente el log.
