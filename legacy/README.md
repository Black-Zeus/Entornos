# Código heredado

`legacy/arch/` conserva componentes históricos para Arch Linux, capturas y el antiguo `config.zip`. No reciben mantenimiento, no son compatibles con Parrot OS y pueden contener prácticas inseguras u obsoletas.

El instalador activo no importa, ejecuta ni depende de este directorio. Su contenido existe únicamente para trazabilidad y consulta durante la migración; no debe ejecutarse en Parrot ni en el host de desarrollo.

Este repositorio no soporta Arch Linux, Kali Linux ni otras distribuciones.
